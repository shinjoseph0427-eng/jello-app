# Technical stack

- Expo SDK 57 / React Native 0.86.3 / React 19.2.3
- Expo Router native tabs, TypeScript strict, Reanimated and Gesture Handler
- TanStack Query for server state; Zustand for capture workflow state
- Supabase Auth, PostgreSQL, private Storage, RPC and Edge Functions
- Expo notifications to APNs; WidgetKit through an EAS-compatible native target

SDK 57 matches the inspected WEEKLY project and the requested Expo Go-compatible baseline. Widget and Apple sign-in validation still require an iOS development build on macOS/physical hardware.
